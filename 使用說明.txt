# 英文自然發音 Phonics 互動教材｜攜帶版

## 內容
- `index.html`：完整 12 單元互動教材，可直接用瀏覽器開啟。
- `manifest.webmanifest`、`sw.js`、`icon.svg`：若放到 HTTPS 靜態網站，可安裝成手機／電腦的網頁 App，並支援快取後離線開啟。

## 在其他電腦使用
1. 解壓縮整個 ZIP。
2. 用 Chrome、Edge、Safari 或 Firefox 開啟 `index.html`。
3. 建議使用 Chrome 或 Edge，並確認裝置音量正常。

## 在手機使用
- Android：將 ZIP 下載並解壓縮，用 Chrome 開啟 `index.html`。不同手機的檔案管理程式對本機 HTML 支援不同。
- iPhone／iPad：將 ZIP 存到「檔案」並解壓縮，點選 `index.html` 用 Safari 預覽。若本機預覽無法正常播放語音，請使用下方 HTTPS 網站方式。

## 想在手機桌面安裝、跨裝置穩定使用
把解壓縮後的**所有檔案**一起上傳到支援 HTTPS 的靜態網站空間（例如 GitHub Pages 或學校網站），不要只上傳 `index.html`。
- Android Chrome：開啟網站 → 瀏覽器選單 →「安裝應用程式」或「加到主畫面」。
- iPhone Safari：開啟網站 → 分享 →「加入主畫面」。
- 第一次開啟網站時保持網路連線；快取完成後可離線開啟教材頁面。

## 語音與動態效果提醒
教材的嘴型開合為示意動畫；語音使用瀏覽器／作業系統內建的英文語音合成。不同裝置的英文語音、聲線與支援程度可能不同。若沒有聲音，請檢查音量、瀏覽器權限與裝置是否有英文語音引擎。
